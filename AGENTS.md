# Aarogya Ayurveda Hospital - Agent Guidelines

## Architecture Overview
- **Framework**: TanStack Start with Vite and React 19
- **Routing**: File-based routing powered by TanStack Router
- **Styling**: Tailwind CSS v4 with custom warm Ayurvedic themes
- **Database & Auth**: Supabase (PostgreSQL, Row Level Security, Auth)
- **ORM**: Drizzle ORM
- **State Management**: TanStack Query (React Query)
- **UI Components**: Radix UI primitives & Lucide React icons

## Development Guidelines
- Always write clean, modular, and type-safe TypeScript code.
- Follow modern React hooks and functional component standards.
- Maintain responsive, accessible designs suited for healthcare users.
